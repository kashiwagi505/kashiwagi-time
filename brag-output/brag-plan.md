# 柏木タイム — 紹介動画プラン

## 何か（一言で）
Java のオブジェクト指向を、図でつかんで・そのまま演習で使ってみる、社内勉強会「柏木タイム」全7回の学習サイト。

- **誰のため**: 変数 / if / for / 配列までは分かる、Java のオブジェクト指向で止まりがちな社内の学習者
- **違い**: 用語の暗記から入らず、図解 → 演習の順。第4回からは「勇者一行」の1本のバトルゲームを育てていく
- **いちばん刺さる事実**: `member.attack()` の1行で、勇者は剣・魔法使いは呪文・タンクは体当たり ──「押すのは同じ、出る技はそれぞれ」（サイトの図Hそのもの）
- **ビジュアルのフック**: 難しい用語の山 → 魔法陣がひらいて、勇者一行のイラストと図解の世界へ
- **見せる実物**: トップのヒーロー、全7回のカード、第6回の図H、演習の「できた」チェックと進捗メーター（すべて本物のHTML/CSS/画像を使う）
- **トーン**: default 寄りの「やさしいRPG」。明るく、きれいに、ちょっと冒険感
- **ひとことキャプション**: 「むずかしい言葉を覚えるより先に、図でつかんで、そのまま使ってみる。」

## アングル
「用語の暗記」の重さ → サイトの答え「図でつかんで、そのまま使ってみる」。用語の山を魔法陣が吹き飛ばして、勇者一行の世界に入る。
